This analysis examines the model buiding accuracy and vairable selection of Fast Sparse algorithm as decribed in the 2022 paper ("Fast Sparse Classification for Generalized Linear and Additive Models" by Liu et al.). This is done by comparing it to the standard LASSO regulaization method in glmnet. On this airline satisfaction dataset (https://www.kaggle.com/code/rajeevnair676/airline-satisfaction-xgboost-96-accuracy), FastSparse achieved slightly better results in accuracy and wiht one less variable needed in the model.
